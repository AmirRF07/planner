اصول تفکیک اطلاعات در مشاور هوشمند:

  • اطلاعات قطعی دانشجو: داده‌های صریح مانند روز کلاس یا نام درس.
  • تخمین‌های دانشجو: مواردی مانند «حدود ۳۰۰ صفحه» که تا زمان ثبت دقیق به عنوان تخمین علامت‌گذاری می‌شوند.
  • پیشنهادهای هوش مصنوعی: روش‌های مطالعه (مانند جدول گاهشمار یا نقد منبع برای تاریخ صفویه).
  • اطلاعات ناقص یا مبهم: مواردی که دستیار بدون حدس زدن جعلی، از شما می‌پرسد (مانند سال امتحان یا بارم‌بندی).

سوابق آزمون‌های آزمایشی و تحلیل خطاها

تولید خروجی استاندارد PDF و Markdown

خروجی‌ها مستقیماً از آخرین داده‌های ذخیره‌شده تولید می‌شوند. خروجی PDF با چیدمان کامل راست‌به‌چپ (RTL)، فونت وزیرمتن، شماره صفحه و پشتیبانی کامل از متون ترکیبی فارسی و انگلیسی تولید می‌گردد.

پشتیبان‌گیری JSON و مدیریت پایگاه داده محلی

توجه مهم درباره حریم خصوصی و ذخیره‌سازی محلی:

کلیه رکوردهای تحصیلی شما صرفاً در پایگاه داده مرورگر (`IndexedDB`) روی همین دستگاه ذخیره می‌شوند و به هیچ فضای ابری ارسال نمی‌گردند. پاک کردن داده‌های سایت در مرورگر (Clear Site Data) می‌تواند منجر به حذف اطلاعات شود و اطلاعات به صورت خودکار بین دستگاه‌های مختلف همگام‌سازی نمی‌شود. توصیه می‌شود به صورت دوره‌ای فایل پشتیبان JSON تهیه کنید.

پیکربندی Gemini API و امنیت ارتباط

شفافیت امنیتی اجرای بدون سرور (Direct Browser-to-Gemini):

از آنجا که این برنامه بدون سرور واسط و مستقیماً روی مرورگر شخصی شما اجرا می‌شود، کلید API شما هرگز در کد منبع قرار ندارد و به هیچ سرور ثالثی غیر از درگاه رسمی Google Gemini ارسال نمی‌شود. به صورت پیش‌فرض کلید تنها در حافظه موقت نشست (`sessionStorage`) نگهداری می‌شود و در فایل‌های پشتیبان JSON ذخیره نمی‌گردد.

مدل‌های نسل ۲.۵ طبق اعلام گوگل برای کلیدهای جدید محدود شده‌اند؛ برای دسترسی پایدار از مدل‌های نسل ۳ استفاده نمایید.
